## Git-дисциплина

1. **Ветка**: работать на своей ветке (`codex/*`, `feature/*` и т.д.), не на `main`
2. **Ни коммитов, ни пушей без просьбы**: дождаться явного требования пользователя
3. **main священна**: никаких `amend`, `reset`, `rebase`, `force-push` на `main`
4. **Новые ветки**: ветвиться от свежего `origin/main`, перед началом — `git pull origin main`
5. **Staging**: `git add <имя-файла>` — только свои файлы по имени, БЕЗ wildcard (никаких `.`, `*`, `-A`)
6. **CRLF-предупреждение** при push (`"LF will be replaced by CRLF"`) — норма, не опасно на Windows

## Подводные камни

### PowerShell 5.1 + кириллица

- **.ps1-файлы с русским текстом** ОБЯЗАТЕЛЬНО должны быть в **UTF-8 с BOM**, иначе парсер падает на кириллице с ошибкой `Unexpected token`
- **Рецепт лечения**: 
  ```powershell
  [System.IO.File]::WriteAllText($path, $content, [System.Text.Encoding]::UTF8)
  ```
  (автоматически добавляет BOM в PS5.1)
- Проверить: ассоциировать `.ps1` в редакторе как UTF-8-с-BOM при создании новых скриптов
