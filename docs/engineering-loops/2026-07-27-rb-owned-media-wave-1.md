копирование не подтверждено. В эту волну вошли только файлы из резервной копии

## Применение и проверка

- Команда `media:import-verified-legacy-images` проверяет SHA-256, MIME,
  опубликованную regional-связь товара, точное совпадение MPN и отсутствие
  обхода пути до копирования файла.
- Файл попадает в постоянное локальное хранилище только со статусом
  `verified` и явным основанием прав. API возвращает только такие записи.
- `GET /api/v1/media/3` и прокси витрины `GET /api/media/3` вернули
  `200 image/png`; карточка DTM6012 проверена визуально в браузере.
- Внешний кандидат Panasonic BR2330 намеренно остаётся `pending`: условия
  производителя не дают основания копировать коммерческое изображение.

## Следующее правило

Дальнейшие legacy-изображения должны проходить ту же цепочку: `b_file` →
archive member → SHA-256 → точная видимая маркировка → подтверждённый MPN →
публикация. Нечитаемая, универсальная или модельно-неоднозначная фотография
остаётся непубличным кандидатом.
