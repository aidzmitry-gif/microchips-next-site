# RB media fail-closed wave 112 — 2026-07-28

## Scope

Forty published, source-described, non-electronic RB cards without verified
media were checked against the company-owned Bitrix upload backup. The input
explicitly excluded the four DELTA products completed in wave 111.

## Result

No new tier-A image passed the exact-model and rights gates. No data was
changed and the strict counter was not increased.

Specific rejects and holds:

- APC RBC31: archive label does not expose a readable exact MPN;
- APC RBC11: label is too small to prove the exact cartridge identity;
- APC SRT192BP2: visible product does not prove the exact SKU;
- Sonnenschein A606/200: the Bitrix base-model form conflicts with the current
  exact MPN `NGA6060200HS0FC`;
- CSB GPL1272: only Ventura GPL12-7.2 and WBR GPL1272 F2 assets were found,
  creating manufacturer/suffix conflicts;
- IPPON Back Basic 1050 Euro: the linked Bitrix asset filename explicitly says
  `back_basic_650_euro_1.jpg`, so it cannot be used for the 1050 model;
- remaining supplied IDs: no exact same-brand plus MPN legacy image was found.

Manufacturer-hosted images were not substituted because the research record
contains no explicit commercial reuse licence. A generic or visually similar
picture is not sufficient evidence for publication.

## Counter effect

- verified published media products: 44 (`+0`);
- strict non-electronic content-complete cards: **44 / 7,286 = 0.60%**;
- no false readiness credit was awarded.
