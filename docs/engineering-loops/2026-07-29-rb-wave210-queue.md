# RB Wave210 no-repeat queue

Wave210 deterministically appends the 500-row Wave208 priority queue to the
1,000-row Wave208 processed register, yielding a 1,500-row unique processed
register. The existing pinned priority builder and source planner then select
the next 500 incomplete B2B candidates from the Wave172 readiness and
cumulative-holds inputs.

The orchestration pins input hashes and row counts, proves zero overlap at each
boundary, applies the source planner automotive/electronics gates, and reruns
all generated artifacts byte-for-byte. It is planning only: web requests and
database mutations are both zero, and every selected row remains unsafe to
apply.

Verification:

- `python scripts/build-rb-wave210-queue.py`
- `python -m pytest scripts/tests/test_wave210_queue.py`
