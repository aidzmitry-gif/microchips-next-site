## Результат

В локальной RB-витрине опубликованы четыре подтверждённые карточки:

- Panasonic BR2330 (`КА-00004377`), раздел `/catalog/primary-cells`;
- Maxell CR2032 1HF (`КА-00000110`), раздел `/catalog/primary-cells`;
- OMRON CJ1W-BAT01 (`КА-00003325`), раздел `/catalog/electronic-components`;

Для каждой карточки выполнены инварианты:

- описание и технические характеристики уже применены из официального источника;
- производитель и MPN заполнены только при пустых канонических полях;
- создан один стабильный URL, связанный с ровно одной категорией;
- цена остаётся `NULL`, доступность — `on_request`;
- URL и SEO-запись — `noindex`; `Offer` schema не создаётся;
- опубликованы только нужные четыре категории из дерева, не весь каталог.

## Контрольный запуск

```text
catalog:publish-source-verified-preview-wave microchips-by /tmp/rb-source-verified-preview-wave.json
products: 4
categories: 4
indexable_urls: 0
offers_created: 0
```

Dry-run выполнен до `--apply`; итоговый apply вернул те же счётчики.

## Витрина

- `/catalog` больше не является 404: это виртуальный, всегда `noindex` корень опубликованного дерева;
- браузерная проверка подтверждает корень каталога, дерево разделов, поиск, сортировку, форму запроса и фактический профиль РБ;
- после четвёртой волны исправлена revalidation: изменение опубликованного товара, категории или связи товара с категорией всегда включает `/catalog`; браузерная повторная проверка показала счётчик `4` без ожидания TTL;
- отсутствие изображений показывается честным плейсхолдером. Загрузка фото не начнётся без отдельной проверки источника, прав использования и визуального соответствия товару.

## Что не следует считать готовым

Это не запуск полного каталога и не SEO-релиз. Остальные 7 638 RB-позиций остаются непубличными до прохождения той же проверки идентичности, данных, категории, медиа и коммерческих условий. Все текущие витринные URL намеренно исключены из индексации.
