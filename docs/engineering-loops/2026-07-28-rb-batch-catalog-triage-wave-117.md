# RB batch catalog triage — Wave 117

## Цель

Заменить ручную последовательную проверку сотен карточек пакетным fail-closed
процессом. Процесс не публикует непроверенные данные и не считает похожие
модели дублями автоматически.

## Выполнено

- Одним запуском обработаны 685 карточек текущей очереди обогащения.
- 685 строк сведены к 101 уникальному новому исследовательскому кластеру после
  исключения восьми явно нерелевантных черновиков.
- 381 карточка без устойчивой идентичности сразу поставлена на hold: для них
  не расходуются веб-поиск и машинное зрение.
- 88 похожих пар проверены как модельные кластеры; строгий гейт не разрешил
  автоматически исключить ни одну пару из-за суффиксов, выводов, разъёмов,
  упаковки, происхождения либо отсутствия подтверждённого MPN.
- Восемь неопубликованных карточек вне фокуса РБ (смазка, промышленный дисплей,
  промышленные трансиверы) прошли dry-run и исключены только из связи с сайтом
  `microchips-by`. Канонические товары и другие рынки не изменялись.

покрывать разрыв от 44 до целевых 729 строго готовых карточек.

## Безопасность

- Извлечённые из названия производитель, модель, напряжение, ёмкость и химия —
  только кандидаты; они не записываются в канонические поля.
- `Save` и `Save+`, десятичные значения, `-CH`, F1/F2, коннекторы и упаковки не
  схлопываются.
- Первичные и перезаряжаемые элементы остаются в фокусе. Из фокуса вынесены
  только реальные электронные компоненты и непрофильные материалы.
- Каждый выходной CSV содержит `safe_to_apply=false`; применение возможно
  только отдельным существующим проверочным контуром.
