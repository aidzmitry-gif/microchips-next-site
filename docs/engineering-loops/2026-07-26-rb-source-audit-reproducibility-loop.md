# RB source-audit reproducibility loop — 2026-07-26

## Цель

Повторно выполнить read-only конвейер исходного Bitrix-снимка и убедиться,
что его контрольные артефакты можно воспроизвести до решения о публикации
товарных URL.

## Исправленная причина ложного впечатления о сбое

`extract-bitrix-b2b-catalog-slice.ps1` на шаге чтения
`b_iblock_element` не завершался после второй фазы: он разбирал 22 105 строк
и 49 SQL INSERT-блоков без промежуточного вывода. В скрипте добавлены:

- прогресс на каждые 1 000 строк второй фазы;
- локальная пакетная обработка токенов SQL вместо большого числа вызовов
  PowerShell-функций для каждого поля;
- безопасное разрешение default `OutputDir` для PowerShell 5.1 и self-test.

Изменение не пишет в исходный backup и не публикует товары.
