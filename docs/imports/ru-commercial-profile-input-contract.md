# Входные данные для профиля Microchips Россия

Этот файл — форма для владельца, а не источник для импорта. Не вставляйте
в него данные Беларуси и не указывайте тестовый домен. После заполнения
значения будут перенесены в отдельный JSON-манифест, сначала в dry-run, затем
в непубличные site-scoped drafts и только после проверки — в verified profile.

## Обязательные сведения

| Поле | Значение владельца | Требование |
| --- | --- | --- |
| Домен |  | Реальный RU-домен, без `*.test` |
| Юридическое имя |  | Включая организационно-правовую форму |
| ИНН / ОГРН |  | Идентификаторы юрлица РФ |
| Юридический адрес |  | Полный адрес |
| Адрес выдачи / сервиса |  | Если отличается; иначе указать, что совпадает |
| Основной телефон |  | Российский рабочий номер |
| E-mail |  | Рабочий адрес для заявок |
| Часы работы |  | Часовой пояс, дни и время |
| Валюта | RUB | Подтвердить расчёты в рублях |
| Доставка |  | Оператор/география/как рассчитываются срок и цена |
| Оплата |  | Счёт, НДС/без НДС при необходимости, online checkout только если реально есть |
| Гарантия и возврат |  | Реальные условия и применимый порядок претензий |

## Правила качества

- В каждой строке указывается источник подтверждения: владелец, договор,
  публичная страница или официальный документ, и дата подтверждения.
- Цена, наличие, срок доставки и гарантия конкретного товара не выводятся из
  этого профиля и не выдумываются.
- Сначала будут созданы черновики. Публикация требует отдельного verifier
  note и не включит indexable URL без успешного SEO release-audit.
- Не нужны банковские реквизиты, пароли, webhook-URL или доступы к сервисам.

## Что произойдёт после заполнения

1. Dry-run профильного импорта: 5 коммерческих фактов и обязательные типы
   контактов (`legal_entity`, `address`, `phone`, `email`, `working_hours`).
2. Проверка изоляции: ни один RB contact/fact не появится в RU site_id.
3. Верификация оператором и noindex-страницы РФ.
4. RU preflight: профиль перестаёт блокироваться по
   `COMMERCIAL_PROFILE_INCOMPLETE`; SEO/GEO release и внешний запуск остаются
   отдельными гейтами.
