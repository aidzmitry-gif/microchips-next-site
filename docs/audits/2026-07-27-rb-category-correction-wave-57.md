# RB category correction — wave 57

`КА-00004530` is a Patriot DDR4 memory module. It was briefly classified as a
computer peripheral during the safe computing wave. This is not an accurate
buyer-intent category: RAM is a computer component, and the current taxonomy
does not yet contain a sufficiently supported PC-components leaf.

The draft-only category relation was removed. The 1C product, its source
identity and all other site associations were retained. It will be considered
again only when a meaningful category with enough verified products exists.
