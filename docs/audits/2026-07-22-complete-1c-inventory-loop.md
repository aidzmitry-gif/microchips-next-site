# Инженерный цикл: полная номенклатура 1С

Дата: 2026-07-22. Источник:
`D:\6 Проекты\microchips.by\nomenclature_20260719.csv`.

## Результат

В Laravel добавлен отдельный inventory-слой для полной номенклатуры 1С.
Он сохраняет исходные строки и иерархию, но не создаёт `products`,
`site_products`, URL или публичные страницы.

Команда:

```powershell
php artisan catalog:inventory-1c "D:\6 Проекты\microchips.by\nomenclature_20260719.csv"
```

Повторный запуск обновляет строку по составной идентичности
`source_key + Код 1С + признак группы`. Одинаковый код у группы и товара
разрешён и не считается дублем.

## Исправленный дефект источника

В двух названиях источник использует нестандартное `\"`. Стандартный вызов
PHP `fgetcsv` воспринимал обратный слеш как escape, склеивал соседние записи
и давал только 9 206 CSV-записей, две из которых имели лишние колонки.
Парсер переведён в RFC-режим с отключённым backslash-escape. После исправления
получены те же 9 209 записей, что и при независимом подсчёте PowerShell:
0 невалидных и 0 потерянных.

## Гейты безопасности

- полный inventory отделён от `catalog:stage-1c`;
- требование подтверждённого SKU или MPN для product staging не ослаблено;
- цена, наличие, бренд и MPN не выводятся из названия автоматически;
- исходный payload и SHA-256 сохраняются для аудита;
- повторный импорт не размножает номенклатуру;
- вероятные услуги только помечаются, но не удаляются автоматически.
