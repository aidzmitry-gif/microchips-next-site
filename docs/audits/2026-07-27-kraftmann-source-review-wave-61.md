# KRAFTMANN: проверка источника характеристик (волна 61)

- `ФР-00000329` — `АКБ Крафтманн Арт 03`
- `ФР-00001736` — `АКБ Крафтманн Арт 03`
- `КА-00000228` — `АКБ Крафтманн Арт 04`
- `ФР-00000367` — `АКБ Крафтманн Тип 02`

## Результат

Поиск точных строк `KRAFTMANN + Арт 02/03/04` и `KRAFTMANN + Тип 02`
не дал официальной страницы производителя, паспорта или технической таблицы,
которые можно однозначно связать с этими названиями 1С. В выдаче встречаются
посторонние документы и совпадения по слову «тип», поэтому они не являются
доказательством технологии, напряжения, ёмкости, размеров или совместимости.

## Решение

- Ничего не записывать в характеристики и описание.
- Не назначать ценность, наличие, фото, артикул изготовителя или гарантию.
- Оставить записи непубликованными в очереди ручного/источникового уточнения.
- Вернуться к обогащению только при появлении точного MPN, паспорта или
  официального URL производителя.

Это отрицательная проверка, а не исключение из 1С: исходные записи и их
идентификаторы сохранены.
