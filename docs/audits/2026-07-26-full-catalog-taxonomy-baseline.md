# Базовая карта SEO-дерева полного каталога

Дата: 2026-07-26. Источник — канонический реестр всех строк Bitrix, а не
набор вручную выбранных разделов.

## Результат классификации

| Состояние legacy-пути | Количество | Правило |
| --- | ---: | --- |
| `candidate_after_quality_gate` | 168 | Не менее 8 прямых товаров; публикация возможна только после карточек, canonical и локального коммерческого контента. |
| `content_required` | 81 | 3–7 прямых товаров; нужен оригинальный обзор, FAQ и подтверждённые характеристики. |
| `merge_or_noindex` | 211 | 1–2 прямых товара; не создавать индексируемую посадочную, пока не появится самостоятельная ценность. |
| `navigation_only` | 29 | Товары лежат в дочерних ветках; это раздел навигации, а не автоматическая SEO-страница. |

Всего в полном источнике 489 путей с товарами. Старое дерево не переносится
один к одному: 211 тонких листингов являются кандидатами на объединение или
`noindex`, а не на создание URL.

## Воспроизводимый запуск

```powershell
python ".\scripts\build-full-catalog-taxonomy-evidence.py" `
  --registry ".\docs\audits\generated\full-catalog-canonical-registry.csv" `
  --out ".\docs\audits\generated"
```

Артефакты:

- `full-catalog-taxonomy-evidence.csv` — все пути и обоснование;
- `full-catalog-taxonomy-launch-candidates.csv` — только кандидаты, не разрешение на публикацию;
- `full-catalog-thin-page-candidates.csv` — тонкие листинги для объединения/noindex.

## Инвариант

Количество товаров в дочерних ветках нельзя путать с количеством прямых
товаров листинга. Например, `mikroelektronika` имеет 295 товаров в дереве и
лишь одну прямую позицию: это навигационная категория, а не «тонкая» страница.
