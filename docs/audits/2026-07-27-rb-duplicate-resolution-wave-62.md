# Разрешение строгих дублей RB (волна 62)

## Исключено из RB-витрины

`ФР-00000996` — повтор `ФР-00000994`.

Обе записи 1С имеют одинаковое название аварийного светильника REXANT;
различие только в завершающей точке. У обеих нет артикула, MPN, цены или
технического атрибута, который мог бы объяснить отдельную карточку.
Сохранён более ранний идентификатор `ФР-00000994`.

## Оставшееся совпадение — не дубль

- `КА-00000606` — `ПЭВМ "Z-tech"`
- `КА-00000607` — `ПЭВМ "Z-tech+"`

Знак `+` является частью модельного названия. Нормализатор убирает его,
поэтому сформировал ложную пару. Обе записи остаются черновыми до появления
конфигурации или официальной документации; одну из них удалять нельзя.

## Инварианты

- Исключения затрагивают только непубликованные RB `site_products`.
- Канонические `products`, исходные записи 1С и другие рынки не удаляются.
- После применения пройден `seo:audit microchips-by` без блокирующих ошибок.
